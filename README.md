# Clip3D Viewer (웹앱, 아이패드용)

그린 텍스처를 3D 모델에 입혀 보는 뷰어. 아이패드 사파리에서 열고 공유 → '홈 화면에 추가'.

- 모델: FBX · OBJ · GLB / 텍스처: PNG · JPG · WEBP · PSD · CLIP(캔버스 미리보기)
- 여러 장을 한 번에 고르면 재질 이름과 비슷한 이미지끼리 자동 연결
- ↻ 다시 불러오기: 저장한 파일을 다시 고르면 같은 이름의 재질에 다시 입힘 (웹은 파일 저장을 감지할 수 없음)
- 파일은 기기 안에서만 처리 (서버로 올라가지 않음), 마지막 작업은 브라우저 저장소에
- 조작: 한 손가락 회전 · 두 손가락 이동·확대 · 두 번 톡 시점 초기화

개발: `npm install` → `npm run dev` / 배포: main에 올리면 GitHub Actions가 Pages로
Mac판(Electron): ../clip3d-mac
